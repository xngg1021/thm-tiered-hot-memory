## 本次补修

1. 子串选择同时检查摘要和源文件全文；摘要中的唯一命中不能掩盖另一条正文中的命中。准确 ID 仍直接定位；歧义写入失败而不改索引。
2. 显式 event ID 的重试不再因跨日而冲突。重复确认不推进复核日程；已提交事件即使来源后来移除或条目失效，也只返回 DUPLICATE，不重新激活或写入。新事件仍须通过当前有效性和来源检查。自动 ID 仍按当天生成；跨日重试应提供明确 ID。
3. 异常事件对象、类型、ID、反馈字段和旧索引事件返回明确错误，不因 list 等输入触发未经处理的 Python 异常。
4. 显式指定的配置文件缺失时报错，配置路径先展开。只有缺少所有明确路径时才查询用户主目录，避免 Windows 中即使 HERMES_HOME 已配置仍提前触发 Path.home() 失败。
5. warm 目录为符号链接时拒绝读取。此项不宣称完整文件系统沙箱或防御同权限恶意进程。
6. 修正已有跨平台测试的临时目录规范化与读取失败注入定位；新增断言证明故障注入确实执行，没有跳过或降低原断言。
