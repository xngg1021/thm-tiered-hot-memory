## 二、反证补漏:发现综述未记录的理论反方

对核心理论支柱的检索发现,睡眠巩固与 CLS 理论存在活跃反方文献,综述只引了支持证据:

- Multiple Trace Theory(2021,被引 71):主张海马体在情景记忆提取中持续参与,挑战 CLS"迁移后新皮层独立"的核心假设。
- Remote Memory and the Hippocampus: A Constructive Critique(2018,被引 228):对系统巩固理论的重要批评。
- Glymphatic System Controversies(2020,被引 619):睡眠中大脑主动清理机制的实证争议,直接影响"睡眠=主动垃圾回收"这一公理 4 的生物学依据强度。

检索局限如实声明:间隔效应的边界条件反证,本轮 OpenAlex 关键词检索召回差(返回无关文献),未找到不等于不存在;要穷尽需 Semantic Scholar 引用上下文(需 key)。

判断:THM 的工程机制(离线巩固、主动弱化)不依赖争议中的生物学细节——即使睡眠巩固的机制解释有争议,"定期离线整理"在工程上依然成立。但综述作为理论依据文档,应当记录反方,补一节"理论争议与边界"。

## 三、数学复核:机制自洽,一处形式不一致

激活方程数值复核(全场景):

- 仅 create 条目:第 2 天 A=0.577(低于驱逐线 0.6),但 age>21 天的双条件使实际驱逐发生在第 21 天及以后。机制自洽。
- create + 次日 hit:A=2.707,hit×2 权重的强化效果显著。
- 90 天内 3 次 hit:A=3.066,满足晋升条件。
- 幂律 d=0.5 长尾验证:90 天后贡献 0.105,而指数型衰减仅 0.011,幂律保留长尾更久,选型正确。

一处形式不一致(标注级):综述引用的 ACT-R 标准式为 B = ln(Σ t_j^(-d))(带 ln),架构设计实现为 A = Σ w·(t+1)^(-0.5)(去 ln、加 +1 平滑)。单调变换不影响排序,+1 防除零,实现无错;但两者不一致且未说明,建议在架构设计 3.1 节补一句说明(如"省略 ln 单调变换与 +1 平滑,阈值按此形式标定")。
