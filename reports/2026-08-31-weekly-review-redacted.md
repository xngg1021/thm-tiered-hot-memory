## 二、引擎与索引修复(本次已执行,非提议)

### 2.1 引擎 bug:seed 的 id 生成逻辑错误

`cmd_seed` 用 `len(entries)+1` 生成新条目 id。库内存在空洞 id 时,该算法会撞上已占用 id。本次 seed 把 10 条新条目中的 7 条发成了已有 id,造成同 id 双条目共存,后续 hit/confirm 按 id 操作会产生歧义。

修复:`thm.py` 新增 `_next_id()`,按 `max(id)+1` 发号(与 `cmd_register` 原逻辑一致),`cmd_seed` 与 `cmd_register` 均已切换到该函数。修复后重跑 seed,幂等验证通过(新登记 0 条)。
