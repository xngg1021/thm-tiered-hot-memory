Network/package failures remain failures; never replace them with an invented benchmark.

## Metrics

Main results exclude category 5 adversarial questions. Category 5 is reported separately as a diagnostic only: retrieving a cited supporting turn is not the correct-answer target for an unanswerable question. Categories follow the official data: 1 multi-hop, 2 temporal, 3 open-domain, 4 single-hop, 5 adversarial. The conversational-only 1/2/4 aggregate is also shown.

Question-level any-gold hit rate, all-gold hit rate, macro and micro evidence recall, pre-budget candidate coverage, empty-context rate, actual budget use, p50/p95 end-to-end retrieval latency and query-embedding latency are separate metrics. No answer is generated by this benchmark. Evidence absent from the index and malformed references remain counted and visible; only fully resolved, nonempty annotations enter the main recall denominator. Multi-reference fields with semicolons are parsed; ambiguous ranges are flagged, not silently expanded.

Only raw conversation turns and their supplied speaker/date metadata enter the index. QA questions are inputs to search only. Answers, evidence IDs, categories and generated summaries are not retrieval features. Returned whole-turn text counts toward the complete context budget. No credit is given for IDs that are merely candidates or neighbors not actually included.

The first two sorted conversation IDs define a disclosed development subset; the remaining eight define the held-out reporting subset. The evaluation does not fit parameters on either subset. Report the full protocol and avoid generalization claims based on ten correlated conversations; questions are not independent random trials. Test scores must not silently become a tuning target.

## Status of the user's earlier local report

A user-reported experiment described 425/1966 evidence hits (21.6%), a 600-token cap, 0.38 ms retrieval and 45 mean reported tokens, plus local machine observations. At the start of this implementation, `research/locomo-test/` and its `results.json` were absent from the remote repository. Those figures are retained as user-reported results, not independently reproduced by this runner.

That result does not establish a lexical-retrieval ceiling: query syntax, OR/AND behavior, stemming, speaker metadata, chunking, ordering, result materialization and packing are experimental variables. Raw question text is not an oracle query. A new protocol must not claim to reproduce the missing script.

The reported memory-token figures appear consistent with characters divided by four; without the original tokenizer and serialization trace this is an estimate, not a model-specific count. SQL execution timing is not necessarily complete result-fetch/serialization timing. Different-machine I/O timings cannot be subtracted from unspecified model request times to prove a complete latency decomposition.

No unverified weighted composite recall (83.5% or 92.3%) is a measured THM outcome here. A retrieval evidence rate cannot be directly compared with a 72.9% full-context answer score. Evidence recall and answer accuracy have different denominators and goals; annotated evidence is not always exhaustive. Benchmark participation has no threshold of that kind.

## Remaining limits

The basic lexical path still cannot solve arbitrary paraphrase or implicit reference. The dense path uses a chosen external encoder and introduces build time, memory and inference cost. The provider tests are not live-host integration. Synthetic decay results are not a measured aging curve of real user knowledge. Every optional capability must report whether it actually executed.
